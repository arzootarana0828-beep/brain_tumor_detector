# Brain Tumor Detection

Educational machine-learning project for classifying brain MRI images.

## Classes

- Glioma
- Meningioma
- No Tumor
- Pituitary

## Technology

- Python
- TensorFlow / Keras
- Streamlit

## Status

Project setup is ready. Dataset, model training, evaluation, and prediction features will be added step-by-step.

> This project is for educational purposes and is not a medical diagnostic tool.
